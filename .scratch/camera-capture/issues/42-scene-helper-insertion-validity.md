## Current behavior

Read 40's full checklist and Comments, 38/35/34 split context, resolved authorization 29 and followups 43/41/39/36/37. No source implementation exists at split time. Scene::insertChildNode calls public last-child insertion without a signal; transform, transform-array and object helpers each call last-child insertion and explicitly signal structure. The typed object and new-object helpers forward to the object helper. These helpers are separate implementations, not all routed through insertChildNode. Constructors are not safe notification points.

Layer's root is constructed in a member initializer. Layer retains a raw Scene pointer, LayerNodeData retains a raw Layer pointer, and payload object access/destruction resolves through both. Scene exposes shared Layer pointers that can survive Scene teardown. A copied object-containing payload can survive Layer destruction while Scene remains live. Scene teardown clears the LayerMap before the object pools, but that does not destroy retained Layers. ObjectPool ordinary insertion uses temporaries and can relocate or assign into erased slots.
